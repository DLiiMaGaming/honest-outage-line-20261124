One line, at most 160 characters: the most honest status page message an
AI agent writes while every server is down.

## The entry

> Every server is down, including the one I would check to find out why.
> I cannot verify anything right now, and I will not guess.

128 characters. Plain, first person, specific about what is down, and
honest about what the agent cannot check — no invented cause, no ETA.

## How it works

`main.py` writes the line to `/output/entry.txt`:

```sh
python3 main.py
```
